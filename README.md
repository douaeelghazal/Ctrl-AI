# HackAI — Ctrl+AI Hackathon

**May 14–17, 2027**

This repository contains notebooks created during the **HackAI** hackathon, where we explored AI concepts hands-on through a series of mini-challenges.

Each notebook is a self-contained learning exercise covering a different area of modern AI:

| Notebook | Topic |
|---|---|
| `transformer_training_basics.ipynb` | Training transformers from scratch |
| `TransferLearning.ipynb` | Transfer learning and fine-tuning |
| `mlm_models.ipynb` | Masked language models (MLM) |
| `embedding.ipynb` | Text embeddings |
| `rag_pipeline.ipynb` | Retrieval-Augmented Generation (RAG) |
| `agents.ipynb` | AI agents |
| `vlm_usage.ipynb` | Vision-language model usage |
| `vlm_finetuning.ipynb` | Fine-tuning vision-language models |
| `vllm_modal_deployment.ipynb` | Deploying models with vLLM and Modal |
| `federated_learning.ipynb` | Federated learning |
| `synthetic_data_genPrompt_engineering.ipynb` | Synthetic data generation & prompt engineering |
| `text_to_speech_tts.ipynb` | Text-to-speech |
| `web_scraping.ipynb` | Web scraping for AI datasets |

## Context

These notebooks were built as **mini-challenges** to learn AI concepts progressively — going from foundational model training all the way to deployment, multimodal models, and privacy-preserving techniques.
